# Weather Web App 🌤

A modern weather application that allows users to search for a city and view real-time weather information.

## Features
- Search weather by city
- Displays temperature, wind speed, rain probability and conditions
- 24-hour weather outlook
- Refresh weather data
- Default location using user's current position
- Modern UI design

## Technologies Used
- HTML
- CSS
- JavaScript
- Visual Crossing Weather API

## How to Run the Project
1. Download or clone this repository  
2. Open the project folder  
3. Open `index.html` in your browser  

No installation required.
